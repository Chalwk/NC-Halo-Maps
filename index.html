Welcome to NC Halo Maps

This is the home of NakedChick's custom multiplayer maps for Halo: Combat Evolved and Halo: Custom Edition. Every map is built by hand, released here, and free to download - no forge, no shortcuts, just good old-fashioned level design.

Browse Maps View on GitHub

About the Cartographer

NakedChick has been mapping for the Halo PC/CE community for years, crafting original multiplayer layouts for CTF, Slayer, Oddball, and Race. Every release on this site ships as a ready-to-install map pack - grab it, drop it in your Halo CE maps folder, and you're set.

How Downloads Work

Every map is published as a GitHub Release, complete with a description and the map files attached directly - no third-party download sites, no ads, no waiting.
